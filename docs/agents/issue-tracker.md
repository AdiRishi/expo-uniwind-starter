# Issue Tracker

Issues for this repository live in GitHub Issues for `AdiRishi/expo-uniwind-starter`.

## Agent Rules

- Use GitHub issues for tracked work that should survive beyond the current thread.
- Keep issues independently actionable.
- Prefer vertical slices that an agent can pick up without hidden chat context.
- Link to relevant docs in `docs/agents/`, `docs/adr/`, or `CONTEXT.md` when the issue depends on repo-specific language or decisions.

## Local Scratch Work

Use local markdown notes only for temporary investigation. Do not treat `.scratch/` files as the issue tracker unless this document is updated.
