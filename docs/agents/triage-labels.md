# Triage Labels

This repo uses the default canonical triage roles.

| Role              | Label             |
| ----------------- | ----------------- |
| `needs-triage`    | `needs-triage`    |
| `needs-info`      | `needs-info`      |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix`         | `wontfix`         |

## Meanings

- `needs-triage`: maintainer needs to evaluate the issue.
- `needs-info`: waiting on reporter or owner for missing details.
- `ready-for-agent`: fully specified and safe for an agent to pick up.
- `ready-for-human`: needs human judgment or implementation.
- `wontfix`: will not be actioned.
