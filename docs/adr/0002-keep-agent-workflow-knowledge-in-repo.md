# Keep Agent Workflow Knowledge in the Repository

We keep Codex workflow knowledge in versioned repo files: `AGENTS.md` as the entry map, `CONTEXT.md` for shared language, `docs/agents/` for repeatable agent procedures, and `docs/adr/` for durable decisions. This makes the harness legible to new Codex threads and Codex worktrees without relying on chat history, local memory, or undocumented human setup.
